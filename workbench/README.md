# DuDu-talkvideo 增强三栏审片台

本模板沿用 DuDu 制作项目中持续修改的增强工作台，保留三栏、附件与文件夹、ZIP 导出、删除/撤回、历史、即时保存和输入性能改进。公开版包含可直接生成页面的 `template.html`，不包含作者历史会话、意见数据库或旧项目整页快照。

语义分镜与实际关键帧使用同一镜头 ID。语义阶段说明讲述目的、素材状态、主画面与人物安排；本期语义批准后才生成真实关键帧。后续可以按镜头留意见并局部修改。

```sh
python dudu.py semantic episodes/本期目录
python dudu.py serve episodes/本期目录 --port 8866
```

浏览器意见和附件仍保存在本地 localStorage/IndexedDB，并通过本项目服务自动保存到本期 `feedback/`。首次升级请在原浏览器打开一次迁移；迁移后其他浏览器可从同一项目恢复。页面不再显示全文导出按钮，但 `window.segmentReview.exportData()` 仍可获取完整备份。

精确对象编辑代码保留，但通用画面未提供对象源时按钮禁用；不能声称可拖拽修改任意成片对象。HTML 里的单条意见不自动等于用户批准本期语义方案。

## 当前版式

- 顶部标题区可通过左侧箭头收起和展开，折叠状态保存在本地。
- 播放控制栏保留音频、段落选择、跟随播放、倍速、已删除和撤回上一步。
- 每段仅保留正文输入框，不显示“待看/采用/需要调整/不采用”、状态徽章或版本说明句。
- 图片、GIF、SVG、普通文件和文件夹通过输入框直接粘贴或拖入，不显示附件选择按钮。
- 图片缩略图显示在输入框上方；同一图片字节在一次粘贴及短时重复粘贴中只保存一份。
- `Option/Alt + T` 可在输入框内插入当前镜头与时间；段内切换关键帧时保持页面滚动位置。
- 直接打开未绑定数据的 `workbench/template.html` 时显示说明，并尝试转到本地已绑定项目的 `/review/` 页面。


### 项目文件自动保存

- `feedback/latest.json`：助手直接读取的最新快照，包含逐条 `records`（正文、阶段、镜头、当前版本标记及附件路径）、旧意见、操作历史与提案；`store` 保留原始浏览器状态供完整恢复。`workflowApproved` 始终为false。
- `feedback/attachments/`：原始附件字节，文件名包含完整SHA256和安全化原文件名；文件夹在清单中保留相对路径及浏览器提供的目录信息，不解压或执行附件。拖入文件夹可包含空目录；浏览器“选择文件夹”通常只提供文件，不提供空目录，此既有边界不变。
- `feedback/revisions/`：每次成功保存的完整不可变JSON版本，不删除旧附件，供历史和撤回核对。
- `feedback/conflicts/`：不同旧浏览器或同时编辑发生版本冲突时保存另一份完整意见，原latest不被覆盖；助手可读取两份后处理，不通过助手自检赋予语义批准。

输入仍同步保存到浏览器，约 650ms 内异步启动项目保存；附件只在首次保存时上传原始字节，打字不反复编码或传输已有附件。项目保存状态可通过 `window.segmentWorkbench.projectSync.getState()` 读取；失败时仍保留浏览器记录并重试。未同步完成关闭页面会提示。更新后无需每次用 Computer Use 导出；助手读取 `latest.json` 和其中的附件路径即可，浏览器仍用于视觉与交互审查。

保存接口是本地同源的 `GET/POST /api/workbench/feedback` 与附件上传接口，不上传云端，不修改原稿、素材、批准或成片。写入使用当前服务的随机令牌、项目身份和版本比较；GET/POST 失败或缺失附件时不冒称保存完成。ZIP 和浏览器历史功能保留。

## 保留与边界

HTTP 服务仅监听 `127.0.0.1`，支持音视频 Range 请求。服务不自动写批准，也不向公网上传。HTML 快照本身不代表实时意见已经落盘；保存失败时应先保留浏览器记录并重试。
