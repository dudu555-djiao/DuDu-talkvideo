# DuDu-talkvideo 增强三栏审片台

本模板沿用 DuDu 制作项目中持续修改的增强工作台，保留三栏与附件、文件夹、ZIP 导出、删除/撤回、历史、即时保存和输入性能改进。公开版包含可直接生成页面的 template.html，不包含作者历史会话、意见数据库或旧项目整页快照。

语义分镜与实际关键帧使用同一镜头 ID。语义阶段说明讲述目的、素材状态、主画面与人物安排；本期语义批准后才生成真实关键帧。后续可以按镜头留意见并局部修改。

```sh
python dudu.py semantic episodes/本期目录
python dudu.py serve episodes/本期目录 --port 8866
```

浏览器意见和附件仍保存在本地localStorage/IndexedDB，并通过本项目服务自动保存到本期feedback/。首次升级请在原浏览器打开一次迁移；迁移后其他浏览器可从同一项目恢复。原导出按钮保留，静态旧页或保存失败时仍可完整导出备份。

精确对象编辑代码保留，但通用画面未提供对象源时按钮禁用；不能声称可拖拽修改任意成片对象。HTML 里的单条意见“采用”不自动等于用户批准本期语义方案。


### 项目文件自动保存

- `feedback/latest.json`：助手直接读取的最新快照，包含逐条 `records`（正文、阶段、镜头、当前版本标记及附件路径）、旧意见、操作历史与提案；`store` 保留原始浏览器状态供完整恢复。`workflowApproved` 始终为false。
- `feedback/attachments/`：原始附件字节，文件名包含完整SHA256和安全化原文件名；文件夹在清单中保留相对路径及浏览器提供的目录信息，不解压或执行附件。拖入文件夹可包含空目录；浏览器“选择文件夹”通常只提供文件，不提供空目录，此既有边界不变。
- `feedback/revisions/`：每次成功保存的完整不可变JSON版本，不删除旧附件，供历史和撤回核对。
- `feedback/conflicts/`：不同旧浏览器或同时编辑发生版本冲突时保存另一份完整意见，原latest不被覆盖；助手可读取两份后处理，不通过助手自检赋予语义批准。

输入仍同步保存到浏览器，约650ms内异步启动项目保存；附件只在首次保存时上传原始字节，打字不反复编码/传输已有附件。页面单独显示“项目文件”状态；失败时保留浏览器记录、提示并重试。未同步完成关闭页面会提示。更新后无需每次用Computer Use导出；助手读取latest和其中的附件路径即可，浏览器仍用于视觉/交互审查。

保存接口是本地同源的 `GET/POST /api/workbench/feedback` 与附件上传接口，不上传云端，不修改原稿、素材、批准或成片。写入使用当前服务的随机令牌、项目身份和版本比较；GET/POST失败或缺失附件时不冒称保存完成。原“导出全部意见与附件”、ZIP和浏览器历史功能保留。
