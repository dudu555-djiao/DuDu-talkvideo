# DuDu-talkvideo 增强三栏审片台

本模板沿用 DuDu 制作项目中持续修改的增强工作台，保留三栏与附件、文件夹、ZIP 导出、删除/撤回、历史、即时保存和输入性能改进。公开版包含可直接生成页面的 template.html，不包含作者历史会话、意见数据库或旧项目整页快照。

语义分镜与实际关键帧使用同一镜头 ID。语义阶段说明讲述目的、素材状态、主画面与人物安排；本期语义批准后才生成真实关键帧。后续可以按镜头留意见并局部修改。

```sh
python dudu.py semantic episodes/本期目录
python dudu.py serve episodes/本期目录 --port 8866
```

浏览器意见和附件保存在本地 localStorage/IndexedDB，相同浏览器及相同端口可恢复。换浏览器、端口或电脑前导出意见与附件。本版没有通用意见导入按钮。

精确对象编辑代码保留，但通用画面未提供对象源时按钮禁用；不能声称可拖拽修改任意成片对象。HTML 里的单条意见“采用”不自动等于用户批准本期语义方案。
