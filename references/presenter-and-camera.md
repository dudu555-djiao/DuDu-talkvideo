# 本期出镜选择与运镜

新一期先确认“本期使用 通用 IP 小人物，还是真人出镜？”。本次请求已明确的选择可以直接记录，不重复询问；旧期局部返修沿用已确认模式。素材存在不等于用户选择，只有声音也不能推断要用IP。选真人但缺视频时标待补，不自动回退。

`new` 创建 `presenter-request.json`，初始 pending；`presenter --mode ip|real --quote ... --evidence ...` 记录真实用户原话与出处，将分镜 `presenterMode` 写为对应值。该命令不替用户选择，也不代表语义批准。新期未确认时 `semantic` 拒绝继续。历史无此文件的工程保留兼容，不批量回写历史分镜或审批。

| 设计项目 | IP 小人物 | 真人出镜 |
|---|---|---|
| 主体 | 所选几何角色固定身份，通过看、想、拿、指与道具互动 | 本人真实原片、原声与原口型；以真实手势、视线和句段切点安排 |
| 景别/构图 | 人物情境、图解、媒体、角落讲述按观看任务切换 | 按原片清晰度与构图选择中景/近景、全屏/让位/隐藏；不能无限裁脸 |
| 运动 | 人物与信息分层运动；重点时可克制上移、放大后回位 | 稳定景别为主，重点处克制推进或切景；图解/证据出现时让位，避免说话脸持续漂浮缩放 |
| 信息切换 | 道具、图解与IP反应形成承接 | 本人讲述与真实操作/证据B-roll承接，保留叙述和视线方向连续性 |
| 特别检查 | 停顿闭嘴，身份和受保护部位稳定，不重复角落头像 | 不施加三嘴形、声线、卡通强调动作和卡通弹跳；裁切不伤头顶、手势和字幕安全区 |

两种模式都按文意选择主画面，不套固定几秒一切或每句推进。录屏聚焦仍围绕有效信息，真人模式也不需要每镜露脸。同一条视频不混用真人讲述者与 通用 IP；截图里第三方人物不属于本期讲述者。

每镜在语义源内记录以下计划，让用户在原三栏工作台中审查。静止同样是有效选择，须说明理由。

```json
{
  "cameraPlan": {
    "subject": "本人讲述，讲到结果时切本期真实成果",
    "framing": "中景；给右侧证据留空；字幕保留底部安全区",
    "movement": "开头稳定；重点处切近景；切成果后按有效区域聚焦",
    "reason": "先建立本人经历，再用成果支持结论"
  },
  "ip": {"mode": "hidden", "visible": false},
  "soundPlan": "本人讲述保持安静；成果卡片确有入场动作时考虑本地轻纸声"
}
```

`cameraPlan` 是制作计划，不是已实现自动运镜。真人原片入出点、音画映射和实际相机动画仍由本期实现落地并检查。现有通用渲染器不是自动真人剪辑器；IP模式也需要按内容实现。出镜方式或主画面实质改变属于语义变更，保留旧版并展示新版重新确认，不能改获批源字节。
