# DuDu-talkvideo

<!-- INSTALLED_PROJECT_ROOT -->
本Skill是公开版通用IP视频制作入口。安装时必须保留整个仓库，不能只复制本目录。通过Skill真实路径（解析软链接）向上两层定位项目根；Windows指针安装则读取同目录project-root.json中的projectRoot。项目根必须含scripts/workflow.py、runtime/renderer.js和brand/style-lock.json；缺失时先按仓库README与docs/INSTALL.md安装完整项目。

先读项目PROJECT_STATE.md与brand/style-lock.json。用项目的dudu.py或./dudu执行命令，自动采用本项目.venv，不依赖作者电脑或其他Skill。未完成安装时先运行scripts/bootstrap.py，不要猜测本机专用路径。默认薄荷绿小方块；折纸鸟、小轨道和六套配色全部可用。选择主题、角色和三种基础版式时读项目 references/themes.md。只修改新一期复制的 brand/style-lock.json，不覆盖其他已有项目或已安装 Skill。

## 已定的风格与判断

- 默认 theme=mint、mascot=block，使用薄荷绿小方块与浅色流程版式；保留分栏讲义、深色路径两类模板及其他五套配色。用户未指定时直接用默认，不要求重新选风格。默认1920×1080、30fps，时长随完整旁白。
- 先按完整讲述段落选择主画面，再用段内聚焦、圈注或操作推进。五类主画面是：关系图解、真实操作、原始证据/成果、IP 情境、IP＋少量文字/图形混合讲解。IP 情境也可介绍工具、作类比、连接前后内容，不能只当情绪插图。讲述任务改变时再换主场景；长段不能始终挂同一张头像卡，也不按短语或固定秒数切镜。A/B-roll 按叙事作用区分。
- 左下角IP是独立讲述层。正文画面、真实录屏和图解可同时保留它；挡信息时移动、缩小或隐藏。人物主场景中不再叠放重复角落头像。
- 默认使用同一几何角色的闭嘴/小口/大口三态SVG，停顿闭嘴。嘴形只由本期旁白包络驱动；语义重点可轻微上移和放大再回位。这是有限嘴形动画，不声称音素级口型。用户指定定帧表情或局部动作时，按本期要求冻结其他部分。
- 声音以用户当次提供的成品录音或指定音色为先，刘飞只是默认预设。指定本人克隆音色时核对真实 Speaker ID 与可调用状态；要先听第一段就先做试听，不替换成默认音色。多段录音依实际内容和稿件核对顺序，保留原件，不重复 TTS。凭据仅从本机私有配置读取，不进入项目交付或 Git。
- 正式视频默认使用通用声音预设：低音量96 BPM柔和felt背景乐，加稀疏的纸张、轻点、三音灵感提示。新一期自动带入配置；按本期画面动作和真实配音时间落音效，不复制旧案例的固定秒数、不逐句或逐次张嘴加声。音效对应具体动画事件；配乐密度、旋律和收束随讲述节奏变化并让位旁白。口型测试、用户要求纯旁白、或输入已含完整混音时，明确关闭配乐和音效以免叠加。

## 制作与审查

1. **接稿与取证。** 保存原稿，用 `scripts/workflow.py new` 建独立一期。教程核对实际结果、新闻查原始出处和日期、观点准备案例。记录来源与缺素材，生成示意不能冒充真实操作或证据。
2. **语义分镜。** 按含义编排 `storyboard.json`，记录原句、目的、主画面、素材、重点、IP和读完所需时间。运行 `semantic`，使用本项目增强工作台交付HTML。此时预估时间明确为预估，缺素材明确标待补。
3. **等待用户同意。** 这是用户明确要求的节点。用户没有同意该版语义分镜前，不生成本期关键帧或进入正式配音/渲染。网页意见、助手自检、批准本Skill及历史一期均不能替代本期批准。收到真实同意后，用 `approve --quote ... --evidence ...` 记录原话和出处，绑定分镜SHA。语义实质改动须展示新版再获同意；时间校准/生成帧写sidecar，不改获批源文件。
4. **声音和实际关键帧。** 用本期旁白及字级时间对齐场景与动作，补齐真实素材。声音设计随分镜确定：纸条/媒体入场可用paper，圈注/核对可用tick，确有灵感发现才用idea；需要精确安排时在该镜头填soundCues，以真实词锚点或已核对时间触发。保留独立旁白、音乐、音效和最终混音；人物嘴形只取旁白包络。实际渲染每镜头足够说明结构/重点/结果的关键帧，运行 `review`，在同一个工作台切到关键帧阶段。不能用AI概念图或未实现示意冒充实际关键帧。
5. **完整动画与反馈。** 全片任务须覆盖全部已批准段落，不能把结尾试片或关键帧当成全片完成。用户要求按网页意见修改时，先导出意见与附件、定位当前版本和镜头，再局部返修。既有约定未设额外强制审批点；按当前指示继续连续动画、成片预览与交付。关键帧HTML保留逐镜头意见；未批准的语义变化不得绕过第3步。
6. **验收与交付。** 先核对交付覆盖范围和播放器实际引用版本。核对事实和画面、字幕可读性、头像遮挡、静默闭嘴、强调与回位，再检查连续运动、音频/字幕/帧数/完整解码。交付MP4、SRT、本期工程入口，保留原素材及修改记录；多声音版本共用一个画面母版，再分别封装；仅技术通过不声称完整人工审看完成。公开发布需要用户当次授权。

用户明确指定局部修改或要求展示已批准样片时，只做对应工作；不让固定流程强迫重做已批准内容。画面局部返修优先规划“修改范围＋前后各 2 秒”，按编码与时间条件复用旧片；不兼容时再扩大范围或回退全片渲染，并说明实际方法。只有声音变化时复用画面，只有画面变化且时间不变时保留原声音与字幕。

## 工作台与执行入口

工作台必须使用本项目 `workbench/template.html`（源于用户“做视频”项目增强v9-A）；保持三栏结构及附件、文件夹、撤回、删除、历史、即时保存、导出和输入性能修复。不要从其他Skill原始工作台重新搭建。语义与关键帧沿用同一镜头ID/项目命名空间；新增排版仅为必要审查信息。

精确编辑提案UI已保留，但对象源未接通时按钮禁用，不能宣传已经能直接改任意画面；浏览器历史意见实时数据库不是HTML快照的一部分。换浏览器/端口前导出意见及附件。

- 执行命令与分镜字段：[references/commands.md](references/commands.md)。
- 具体主画面选择、素材和验收逻辑：项目 `references/production-rules.md`。
- 渲染原语、关键帧和动画数据：项目 `references/renderer-schema.md`。
- 需要配音/导入声音时：项目 `references/audio.md`；多录音顺序、克隆音色、VideoTalkCraft 声音设计和三版交付见项目 `references/audio-delivery.md`。
- 挑选 FredTalk 动效、录屏聚焦、指定人物局部动作、网页反馈或局部渲染时：项目 `references/motion-and-revisions.md`。外部 Skill 按需使用，不是必装依赖；适配后仍用本项目工作台与品牌。
- 全流程复盘和已验证案例：项目 `docs/WORKFLOW_REVIEW.md`；案例数值不作新片固定参数。
- 工作台维护：项目 `workbench/README.md`（或同目录复用说明），先核对源版与已验证功能。

现有原语只是制作基础；内容确有需要时扩展本期组件，并检验结果。不要为了套模板把全部内容改成大字标题或假界面。通用模板演示在项目 `examples/public-templates/`，使用合成包络展示状态，不是新一期内容、自然人声演示或生产审批。作者私人角色及旧样片不属于公开素材。
