# 增强三栏工作台

当前实现位于项目 `workbench/template.html`。每期页面由 `scripts/build_review.py` 写入该期 `review/index.html`，再通过 `scripts/serve_review.py` 打开。不要直接把未绑定数据的 `workbench/template.html` 当成本期工作台。

## 页面入口

```sh
./dudu semantic EPISODE
./dudu serve EPISODE --port 8866
```

浏览器打开终端返回的 `http://127.0.0.1:<port>/review/`。直接打开模板文件时，页面会说明模板不含项目数据，并尝试转到本机默认的 `/review/` 入口。

## 当前版式

- 保留三栏主体：原文与分镜说明、媒体或关键帧、意见编辑。
- 顶部标题区可通过左侧箭头收起和展开；折叠状态保存在本地。
- 播放控制栏保留音频、段落选择、跟随播放滚动、倍速、已删除和撤回上一步。
- 已删除按钮切换已删除片段视图；撤回按钮撤回整个版本中最近一次可撤回操作。
- 不显示旧的意见筛选栏、阶段提示、全片播放按钮和全文导出按钮。
- 精确编辑提案沿用原有入口；对象源未接通时保持禁用。

## 意见编辑器

- 每段只保留正文输入框，不显示“待看/采用/需要调整/不采用”、状态徽章或版本说明句。
- 不显示“插入图片/GIF/SVG、添加文件/文件夹、标记当前帧”按钮。
- 图片、GIF、SVG、普通文件和文件夹通过输入框直接粘贴或拖入。
- 图片缩略图统一显示在输入框上方。
- 相同图片字节在一次粘贴和短时重复粘贴中只保存一份。
- 输入框内按 `Option/Alt + T` 可在光标处插入当前镜头与时间。
- 删除本段仍使用每段上方的“删除本段”；查看已删除内容使用顶部播放控制栏。

## 交互约束

- 点击段内上一帧、下一帧或缩略图时，保持当前页面滚动位置，不触发跟随播放的自动滚屏。
- 附件读取、保存或项目同步失败时保留原浏览器记录，不把失败显示成已保存。
- 意见与原始附件同步到本期 `feedback/latest.json`、`feedback/attachments/` 和 `feedback/revisions/`。
- 页面按钮、localStorage/IndexedDB 与项目文件保存是三层证据；HTML 静态截图本身不代表意见已落盘。

## 修改与验证

修改共享 `workbench/template.html` 后，应重新绑定本期 `review/index.html`，保留其中已有的工作台数据。至少验证：

1. 镜头和关键帧仍正常加载。
2. 顶部收起/展开与本地状态恢复。
3. 删除、已删除视图和撤回。
4. 段内切换帧不改变页面滚动位置。
5. 同一图片单次或重复粘贴只生成一张缩略图。
6. 文字、普通文件、SVG、GIF 和文件夹可以保存并在刷新后恢复。
7. 浏览器控制台无脚本错误，`feedback/latest.json` 正常更新。
